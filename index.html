💻 Commands

All commands use prefix R

🎵
Rplay
Play a song by name or URL
⏭️
Rskip
Skip to the next song
⏹️
Rstop
Stop music and clear queue
📋
Rqueue
Show the current song queue
⏸️
Rpause
Pause the current song
▶️
Rresume
Resume the paused song
🎶
Rnowplaying
Show the current playing song
📝
Rlyrics
Get lyrics of the current song
🔊
Rvolume
Set volume (0-100)
🔀
Rshuffle
Shuffle the song queue
🔁
Rloop
Loop current song or queue
❓
Rhelp
Show all available commands
